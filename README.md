# Libella
pagina de la constructora libella 

## Lenguajes y tecnologías utilizadas

- **Python**: scripts, automatizaciones y/o lógica backend.
- **TypeScript**: scripts del lado del cliente y lógica general del proyecto.
- **Node.js**: ejecución de JavaScript en el servidor, gestión de dependencias y herramientas de desarrollo.
- **React**: construcción de interfaces de usuario interactivas y reutilizables (frontend).
- **CSS**: estilos personalizados y/o frameworks de estilos para darle presentación a la aplicación.
- **Vite**: para correr el proyecto
- **Sonner**: para algunos estilos necesarios en alguna de las paginas

## Instalación
1. Clone el repositorio = git clone https://github.com/dokiromboide/Libella.git
2. Instale las dependencias de Node.js/React/TypeScript/etc = npm install
3. instale las dependencias de Python = pip install -r requirements.txt (si corresponde para lo que está haciendo)
